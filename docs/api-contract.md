## Conventions

- All responses are JSON.
- All errors have the shape `{ "message": "..." }`.
- Every album has a string `id`, generated by the server.
- `year` is a number, or absent.

---

## GET /api/albums

Returns every album. Optionally filtered.

**Query parameters**

| Name | Type | Required | Description |
|---|---|---|---|
| artist | string | no | Partial, case-insensitive match on artist |

**Success — 200**

```json
[
  { "id": "a1", "title": "Nevermind", "artist": "Nirvana", "year": 1991 }
]
```

Returns `[]` when nothing matches. Never `null`, never 404.

**Errors**

| Status | When |
|---|---|
| 500 | Something went wrong on the server |
